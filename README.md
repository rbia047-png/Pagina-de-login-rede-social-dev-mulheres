💗 DevGirls — Rede Social para Mulheres na Tecnologia

O DevGirls é um projeto de rede social desenvolvido com o objetivo de conectar mulheres que compartilham o interesse por programação e tecnologia. A proposta é criar um espaço para compartilhar conhecimentos, divulgar projetos, fazer networking e incentivar o crescimento profissional feminino na área de desenvolvimento.

Tecnologias utilizadas: HTML5, CSS3 e JavaScript.

Funcionalidades: página de login, recuperação e redefinição de senha e formulário de criação de conta.

Objetivo: praticar desenvolvimento front-end, aprimorar habilidades em HTML, CSS e JavaScript e criar uma interface moderna, responsiva e acolhedora.

🚀 Projeto acadêmico e pessoal em desenvolvimento.
